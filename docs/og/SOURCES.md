# Open Graph logo sources

Assets under `logos/` are used when building `icons/og.png` (see `og-card.html` and `README.md` in this folder).

Trademark note: logos identify supported label-maker brands on an unofficial OSS companion site (nominative use). Kept modest in a strip. Rights remain with the respective owners. Do not treat this folder as a licence to reuse the marks elsewhere. See also `TRADEMARK.md` at the repo root.
