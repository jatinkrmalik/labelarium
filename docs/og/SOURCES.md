# Labelarium OG lab sources

Two 1200×630 social cards, rendered from HTML in this folder.

- `og-brands-logos.html` → `og-brands-logos.png` (official brand marks)
- `og-brands-type.html` → `og-brands-type.png` (names in Labelarium type)

Preview copies: `og-brands-logos-preview.png`, `og-brands-type-preview.png`.

App icon: `icon-512.png` (new ABC tape mark, warm paper, no inner plate, no red LED). Same mark as `/workspace/wt-seo-og/icons/icon-512.png`.

Fonts: local `fonts/` (Bodoni Moda 400, Jost 400/500/600), TTF and WOFF2.

Render: Chromium at device scale 2, then Lanczos to exactly 1200×630.
